# 🔐 Automatic Password Generator

A modern and responsive Password Generator Web Application built using HTML, CSS, and JavaScript.

This application generates strong random passwords with customizable options such as uppercase letters, lowercase letters, numbers, symbols, and password length.

---

# 🚀 Features

✅ Generate secure random passwords  
✅ Select custom password length  
✅ Include uppercase letters  
✅ Include lowercase letters  
✅ Include numbers  
✅ Include symbols  
✅ Copy password to clipboard  
✅ Responsive modern UI  
✅ Works on desktop and mobile browsers

# ▶️ How to Run the Project

## Method 1: Open Directly

1. Download or clone the project
2. Open the project folder
3. Double-click `index.html`

The project will open in your browser.

---

## Method 2: Using VS Code Live Server

1. Open project in VS Code
2. Install Live Server extension
3. Right-click `index.html`
4. Click **Open with Live Server**

---

# 🔧 How It Works

1. User selects password options
2. JavaScript collects selected character sets
3. Random characters are generated
4. Password is displayed instantly
5. Copy button copies password to clipboard
